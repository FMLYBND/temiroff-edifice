# Промт для Grok Build — правки страницы «3D-стройка»

> Кидать целиком. Ниже в блоке «ЗАДАЧА» — вписать, что поменять.

## Контекст
Репозиторий `FMLYBND/temiroff-edifice` — статический сайт сметы реконструкции БЦ в Навои. GitHub Pages, сборки нет. Сайт обязан открываться **офлайн** двойным кликом по `model.html` (file://): никаких CDN, npm-импортов, модулей ES, Google Fonts.

Страница `model.html` — 3D-модель стройки по 10 этапам (Three.js r147 из `assets/vendor/three/`).

| Файл | Что внутри | Когда править |
|---|---|---|
| `assets/model-data.js` | `window.EDIFICE_MODEL`: размеры, уровни, оси, фасады, шахта и двери лифта, два варианта надстройки, виды камеры, тексты и факты этапов, какие договоры/этажи дают статус этапу | **почти всегда только его** |
| `assets/model.js` | сцена, геометрия, анимация, UI (IIFE, ES2017, без модулей) | новая геометрия или поведение |
| `assets/site.css` | блок в конце с префиксом `.m-` | вид панелей |
| `assets/model-private.js` | внутренние заметки («проверить», ГАСН) — **в .gitignore, не коммитить** | локально |
| `assets/model-private.example.js` | шаблон приватного файла | если меняется структура |
| `assets/data.js` | данные сайта (договоры `contracts`, `lift.items`, `floors`) — 360 КБ, целиком не читать | статусы этапов берутся отсюда |
| `docs/model-changelog.md` | журнал правок «было → стало → основание» | **каждая правка чисел** |

Система координат: x — вдоль фасада 1 от левого угла (0…13,7); yr — от тыльной стены (0…16,3); в Three.js `z = −16.3 + yr`. Отметки в метрах от ±0.000.

## Правила
1. Числа — только из документа (КЖ, АС, АИ, план v4). Нет документа — пометить в фактах этапа источником `"допущение"`.
2. Каждую правку чисел записать в `docs/model-changelog.md` строкой «было → стало → основание».
3. Конфликты (оголовок +14.900, остановка +10.200 против пола +10.800) **не прятать** — они в `conflicts` и на сцене.
4. Статусы этапов не хардкодить: они считаются из `data.js` по `stages[].status` (`contracts`, `lift`, `floors`). Правило: берётся наименее продвинутая стадия; «готово» — только если готово всё.
5. Внутренние тексты («проверить», претензии к актам, ГАСН) — только в `assets/model-private.js`, никогда в публичные файлы. Показываются только после входа admin / manager.
6. Не трогать `main`, работать в своей ветке, мелкими коммитами.
7. Стили — только классы с префиксом `.m-`.

## Проверка перед коммитом
- `node --check assets/model.js assets/model-data.js`
- Открыть `model.html` через file:// → консоль без ошибок.
- Прокрутить этапы 00 → 09 и назад, кнопки «сейчас», виды «Угол / Фасад 1 / Фасад 2 / Сверху / Лифт», «Рентген», переключатель «Надстройка».
- Проверить ширину 390 px (телефон): карточка сворачивается, панели не перекрывают друг друга.
- `index.html`, `lift.html`, `works.html` открываются без ошибок.
