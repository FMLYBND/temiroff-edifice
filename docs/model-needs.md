## Как присылать обновления

Одной строкой на факт:

```
этап / элемент — что произошло — дата — основание (акт, фото, обмер, чертёж)
```

Пример: `02 кровля — стяжка снята полностью, плиты ПК сняты 2 шт. — 03.10.2026 — фото`.
Без основания правка числа идёт в модель с пометкой «допущение».
