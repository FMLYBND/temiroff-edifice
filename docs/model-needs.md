## Как присылать обновления

Одной строкой на факт — она ляжет записью в `site` (ось «факт», `model-data.js`) и сразу сдвинет статус этапа:

```
этап / элемент — что произошло — дата — основание (акт, фото, обмер, чертёж)
```

Пример: `шахта — колонна 8,6 факт 420×410, свет 2380 — 05.10 — обмер`.
Без основания правка числа идёт в модель с пометкой «допущение».
